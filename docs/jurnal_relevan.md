# Jurnal Relevan Neural Network untuk Prediksi Penyakit Jantung

## Pendahuluan

Pada project ini digunakan metode Neural Network untuk melakukan klasifikasi risiko penyakit jantung berdasarkan data medis pasien. Untuk mendukung implementasi yang dilakukan, digunakan dua jurnal yang relevan dengan penggunaan Artificial Neural Network pada kasus prediksi penyakit jantung.

---

# Jurnal 1

## Informasi Jurnal

Judul:

Neural Network-Based Coronary Heart Disease Risk Prediction Using Feature Correlation Analysis

Penulis:

Jae Kwon Kim, Sanggil Kang

Tahun:

2017

Publisher:

Journal of Healthcare Engineering

DOI:

10.1155/2017/2780501

Link:

https://pubmed.ncbi.nlm.nih.gov/29065583/

---

## Latar Belakang

Penyakit jantung koroner merupakan salah satu penyebab kematian terbesar di dunia. Banyak faktor seperti tekanan darah, usia, kadar kolesterol, dan gaya hidup dapat mempengaruhi risiko penyakit jantung. Penelitian ini mencoba menggunakan Neural Network untuk membantu melakukan prediksi risiko penyakit jantung secara otomatis.

---

## Metode Penelitian

Penelitian menggunakan pendekatan Neural Network dengan tambahan Feature Correlation Analysis untuk memilih fitur yang paling relevan.

Tahapan penelitian:

1. Pengumpulan data pasien
2. Analisis korelasi fitur
3. Seleksi fitur penting
4. Pelatihan model Neural Network
5. Evaluasi performa model

---

## Hasil Penelitian

Penelitian menunjukkan bahwa:

* Neural Network mampu mempelajari pola kompleks dari data medis pasien
* Seleksi fitur meningkatkan performa model
* Neural Network menghasilkan performa prediksi yang baik untuk klasifikasi penyakit jantung

Penelitian menunjukkan bahwa kombinasi Feature Selection dan Neural Network dapat meningkatkan kemampuan prediksi dibandingkan penggunaan fitur tanpa seleksi.

---

## Hubungan Dengan Project

Hubungan jurnal ini dengan project yang dilakukan:

* Sama-sama menggunakan Neural Network
* Sama-sama melakukan klasifikasi penyakit jantung
* Sama-sama menggunakan atribut medis pasien sebagai input model

Karena itu penelitian ini sangat relevan untuk digunakan sebagai referensi.

---

# Jurnal 2

## Informasi Jurnal

Judul:

Heart Disease Prediction Using Artificial Neural Network

Publisher:

International Journal of Advanced Research in Computer and Communication Engineering (IJARCCE)

Link:

https://ijarcce.com/papers/heart-disease-prediction-using-artificial-neural-network/

---

## Latar Belakang

Jumlah data medis yang besar membuat proses diagnosis manual menjadi semakin sulit. Oleh karena itu dibutuhkan metode komputasi yang dapat membantu tenaga medis melakukan prediksi penyakit jantung secara lebih cepat.

Penelitian ini mengembangkan sistem prediksi penyakit jantung menggunakan Artificial Neural Network.

---

## Metode Penelitian

Penelitian menggunakan:

* Artificial Neural Network
* Backpropagation Algorithm
* Dataset klinis pasien

Tahapan penelitian:

1. Data preprocessing
2. Training model ANN
3. Testing model
4. Evaluasi performa

Penelitian menggunakan 13 fitur klinis pasien sebagai input model Neural Network.

---

## Hasil Penelitian

Penelitian menunjukkan bahwa:

* Artificial Neural Network dapat melakukan klasifikasi penyakit jantung dengan baik
* Backpropagation mampu meningkatkan proses pembelajaran model
* ANN menghasilkan performa yang tinggi dalam proses prediksi

Penelitian menyimpulkan bahwa Neural Network cocok digunakan sebagai sistem pendukung keputusan untuk membantu diagnosis penyakit jantung.

---

## Hubungan Dengan Project

Hubungan dengan project:

* Menggunakan Artificial Neural Network
* Menggunakan data medis pasien
* Sama-sama melakukan klasifikasi penyakit jantung
* Menggunakan pendekatan supervised learning

Karena metode yang digunakan sangat mirip, jurnal ini dapat digunakan sebagai referensi implementasi project.

---

# Kesimpulan

Berdasarkan kedua jurnal tersebut dapat disimpulkan bahwa Neural Network merupakan metode yang cukup efektif untuk menyelesaikan permasalahan prediksi penyakit jantung.

Kedua penelitian menunjukkan bahwa:

* Neural Network mampu menangani pola kompleks pada data medis
* Neural Network cocok digunakan untuk klasifikasi penyakit jantung
* Penggunaan preprocessing dan feature selection dapat meningkatkan performa model

Oleh karena itu, penggunaan Neural Network pada project prediksi penyakit jantung ini memiliki dasar penelitian yang kuat dan relevan.
