# Heart Disease Prediction Using Neural Network

## Deskripsi Project

Project ini bertujuan untuk melakukan prediksi risiko penyakit jantung menggunakan metode Neural Network berdasarkan data medis pasien.

Dataset yang digunakan berasal dari Kaggle Heart Disease Dataset.

## Studi Kasus

Memprediksi apakah seorang pasien memiliki risiko penyakit jantung berdasarkan atribut medis pasien.

## Dataset

Source:

https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset/data
